# 2026-11-13 전수·장시간 검증

장문 경계에서 실제 오류 1건을 찾아 수정했다. 수정 후 고정 정답 415건은 **402 PASS / 0 FAIL / 13 UNVERIFIED**다. 아래 전수·장시간 검사도 통과했다. 실제 장치·전문 촉독·규정 전체 적합성의 완료 선언은 아니다.

## 정답 근거와 안정성 검사의 구분

| 층 | 근거/입력 | 결과가 뜻하는 것 |
|---|---|---|
| 공식 고정 정답 312건 | 공식 표 33, 실제 예 113, PDF 좌표로 추가한 예 161, 실제 예문 일부 5 | 해당 입력을 공식 표·예시와 대조 |
| 수작업 조합 90건 | 조항으로 직접 조합한 기대값 | 조항 해석과의 일치; 공식 예문 자체는 아님 |
| 정책/미지원 13건 | 표시 정책 5, 미지원·미검증 8 | 회귀 검사에 성공해도 규정 판정 UNVERIFIED |
| 조항 기반 생성 기대값 | Python Unicode NFD + 별도로 전사한 점형 사실 | 별도 구현한 기대값과의 일치; 전문 점역기 검증은 아님 |
| 불량 입력/상태 반복 | 고정 시드, 바이트·길이·진단·페이지·패킷 불변 조건 | 범위·상태·거부 동작 확인; 언어 점역 정답은 아님 |
| AddressSanitizer | MSVC 메모리 오류 계측 | 실행 경로에서 ASAN 보고 없음; MSVC 누수 전용 검사나 실기 검증은 아님 |

## 전수 범위

- 현대 한글 11172자의 단독 점역과 숫자 0~9 각각을 앞세운 점역을 생성 기대값과 대조했다.
- `11172 × 11172 = 124813584` 인접 음절 조합을 각 빌드에서 한 번씩 대조했다. 고유 입력은 124813584쌍이며 두 번 실행한 수를 서로 다른 입력 수로 부풀리지 않는다.
- 두 번째 음절의 초성 ㅇ, 제14항 ㅏ 예외, 제11·12항 모음 연쇄, 받침·겹받침·성/셩 구분을 함께 확인했다.
- 7개 약어 앞에 모든 현대 음절을 붙여 약어 금지를 확인했다.
- U+0000~U+10FFFF 인코딩/디코딩: 유효 스칼라는 복원하고 surrogate 2048개는 거부했다. 모든 임의 4바이트 문자열 전수 검사를 뜻하지 않는다.
- 모든 2바이트 조합 65536개와 길이 0~4097의 7개 입력 계열을 검사했다.
- 잘못된 UTF-8, NFD, 문장부호, 숫자, 로마자, 미지원 문자 혼합에 대해 측정/출력 크기·unsupported 일치, 진단 위치·셀 범위, Pager 거부·큐·페이지 상한을 검사했다.
- 시드는 `4541524c494e4b24`다. 시간 기반 종료이므로 최종 반복 수는 장비마다 달라도 같은 시드의 입력 앞부분은 재현된다.

## 발견하고 수정한 오류

`"? "`를 2048회 반복하면 4096바이트다. 단독 물음표의 제49항 설명 주석 때문에 총 28672셀이 필요하지만 상한은 24592셀이다.

- 수정 전: 24592셀에서 잘렸지만 `unsupported=0`이었다. 잘린 메시지가 정상 등록될 수 있었다.
- 수정 후: 최초 초과 위치에서 `LIMIT.output-cells`를 한 번 기록하고 `unsupported=1`로 반환한다. BLE/Pager는 메시지 전체를 거부한다.
- 상한은 유지했다. 정확히 상한에 맞는 입력과 한 셀 초과한 입력도 회귀 검사한다.
- 바이트당 6셀은 절대 최대 확장률이 아니다. 메모리 제한을 넘으면 지금은 명시적 오류로 처리한다.

[재현 전후](regressions.json), 회귀 코드: `tests/core_test.cpp`.

## 공식 PDF 대조

같은 기준선의 낱말과 뒤의 `HSBRL` 글꼴을 좌표로 짝지었다. 조문 설명 3개를 제외한 229개 낱말/점형을 검토하고, 기존과 겹치지 않는 161개를 고정 정답에 추가했다. 기대값을 펌웨어 출력으로 생성하거나 수정하지 않았다.

공식 고정 정답 312건의 비어 있지 않은 점형열이 출처 쪽에 존재함을 원본 글꼴에서 추가 확인했다. 이 기계적 검사는 공백·정확한 단어 정렬·조항 해석까지 보증하지 않는다. [대조 기록](official-source-audit.json), [좌표 corpus](../tests/official_words_2024.json).

## 재현과 한계

```powershell
npm.cmd run test:firmware
npm.cmd run test:firmware:deep
npm.cmd run test:firmware:asan
```

생성기는 펌웨어 테이블이나 출력값을 읽지 않지만 **같은 규정 해석 오류를 두 구현이 공유할 가능성은 남는다.** 생성 수백만 건을 공식 직접 예문 대조나 전문 검수 수백만 건으로 표시하지 않는다.

ASAN은 PC의 MSVC x64 실행이다. ESP32 메모리 배치, FreeRTOS/BLE 병행 실행과 실물 타이밍, 코일 전력·발열·촉독은 검증하지 않았다. 기존 출력 262144조합 비교도 소프트웨어 호환성 검사다. 일반 UEB·일부 단독 된소리·옛한글·특수 의미 문맥은 [미지원 목록](../RULES_2024.md)에 남는다.
